TITLE (tentativo):
  "Broadcast Beam-Steered Optical Wireless Positioning: 
   3D Localization Without Cooperative Alignment"

================================================================================
 NARRATIVA
================================================================================

PROBLEMA:
  El beam-steered OWP (TCOM) requiere una medición cooperativa (K+1) para
  recuperar distancia. Esto requiere PD reorientation → imposibilita broadcast
  a múltiples usuarios simultáneamente.

SOLUCIÓN:
  Explotar la información de distancia contenida en las K potencias absolutas
  (no solo en las ratios que usa GLS), usando n_r conocido vía IMU.
  → Broadcast 3D positioning sin medición cooperativa.

RESULTADO CLAVE:
  NLS + broadcast_distance = profiled MLE → alcanza el PEB_B (CRLB broadcast).
  Penalización broadcast ρ = PEB_B/PEB_C ≈ 1.2–1.8× dependiendo de K.
  A cambio: escalabilidad total (N receptores simultáneos con un solo LED scan).

================================================================================
 TERMINOLOGÍA FORMAL
================================================================================

  PEB_B  = Broadcast PEB  (CRLB, solo K mediciones, n_r conocido)
  PEB_C  = Cooperative PEB (CRLB, K+1 mediciones, TCOM)
  DEB    = Direction Error Bound (CRLB dirección, n_r-independiente)
  J_B    = Broadcast FIM
  J_C    = Cooperative FIM = J_B + rango-1 PSD
  ρ(r)   = PEB_B(r) / PEB_C(r) ≥ 1  (penalización broadcast)

 ESTRUCTURA DEL PAPER (6 páginas IEEE)
================================================================================

Section I — Introduction (1 pág)
  - OWP state-of-the-art: multi-LED vs single-LED
  - Limitación del beam-steered OWP: medición K+1 cooperativa, no escala
  - Contribución: arquitectura broadcast + PEB_B + estimador near-optimal
  - Organización del paper

Section II — System Model and Broadcast Architecture (1 pág)
  - Modelo de canal Lambertiano (recap breve del TCOM)
  - Arquitectura broadcast: K mediciones, n_r conocido (IMU)
  - Estimador de amplitud: η̂ = Σ μ̂_i Q̂_i^m / Σ Q̂_i^{2m}
  - Distancia: d̂ = √(C·cos(ψ̂) / η̂)
  → Fig. 1: Trayectorias 3D multi-usuario (sim11) [FLAGSHIP]

Section III — Broadcast Position Error Bound (1 pág)
  - FIM broadcast: J_B = (N/σ²) Σ [∇_r μ_i][∇_r μ_i]^T
  - PEB_B = √tr(J_B⁻¹)
  - Relación formal: J_C = J_B + PSD → PEB_C ≤ PEB_B (Loewner)
  - Dependencia de n_r (vs DEB que es n_r-independiente)
  → Fig. 2: Heatmap PEB_B para K=5 y K=9 (sim01)

Section IV — Parametric Analysis (1.5 pág)
  IV-A. Efecto de K (número de orientaciones)
    → Fig. 3: PEB_B vs K para Φ_{1/2} ∈ {30°,45°,60°} (sim02)
  IV-B. Efecto del receiver tilt
    → Fig. 4: PEB_B vs θ_tilt para K=5,7,9 (sim06)
  IV-C. Efecto del SNR
    → Fig. 5: PEB_B vs SNR con envelope K=5..15 (sim03)

Section V — Estimator Performance (1 pág)
  - NLS + broadcast_distance = profiled MLE → near-efficient
  - GLS/WLS subóptimos (descartan info distancia al usar ratios)
  → Fig. 6: CDF de error 3D, K=5 (solid) y K=9 (dashed) (sim05)
  → Table I: RMSE, CDF90, APE, latencia

Section VI — Conclusion (0.5 pág)
  - Broadcast viable con penalización ρ ≈ 1.2–1.8×
  - Trade-off: n_r requerido para distancia, a cambio de escalabilidad
  - Future work: orientaciones optimizadas para PEB_B, validación experimental

================================================================================
 PUNTOS PARA DISCUTIR / DECISIONES PENDIENTES
================================================================================

  1. Orientaciones: se usan DEB-optimizadas (del TCOM). NO se re-optimizan
     para PEB_B. Es el escenario práctico. Mencionarlo como future work.

  2. Degradación con tilt: viene de (a) SNR baja por cos(ψ)<1, y
     (b) posiciones fuera del FOV. No es falla del IMU.

  3. Nivel de ruido σ²: se usa σ²=3e-14 (14 dB, consistente con TCOM).
     Para DC/NIR filtrado sería ~24 dB. La Fig.5 (PEB vs SNR) cubre todo.

  4. Φ_{1/2}: se fija a 45° para la mayoría de figuras. Fig.3 muestra
     el efecto de variarlo.

  5. NLS es near-optimal porque es el profiled MLE (estima n_d y η
     conjuntamente). GLS/WLS son subóptimos porque descartan η al tomar
     ratios. Ver analysis_why_NLS_achieves_PEB_B.md para justificación.
